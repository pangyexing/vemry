# Preregistration and the file drawer

The file-drawer problem is not that researchers lie. It is that a study which found nothing is less interesting to write up than one that found something, and the aggregate of many small, honest decisions is a literature that looks more certain than the evidence underneath it.

Pre-registration does not fix this by making people honest. It fixes it by moving the interesting decision — what counts as a result — to before the data exists, when it cannot be made in the result's favour.

Filed against the protocol rule in [[Nap Experiment]] and the caveat in [[Open Questions]].
