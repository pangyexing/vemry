# 遗忘曲线与间隔重复

学习方法讲义　第 3 讲

## 一、遗忘从什么时候开始

1885 年，艾宾浩斯用无意义音节做记忆实验，发现遗忘在学习后的最初几个小时里最快，之后逐渐放缓。这条先陡后平的曲线，后来被称为遗忘曲线。

## 二、间隔重复

如果在快要忘记的时候复习一次，记忆就会比上一次保持得更久。把复习的间隔逐次拉长，就能用更少的次数记住同样多的内容，这就是间隔重复。

间隔该拉多长，取决于每次回忆的难易：想起来很吃力，下次就早一点；毫不费力，就可以再往后推。
