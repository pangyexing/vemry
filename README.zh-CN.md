**你的笔记就是文件。** 纯 Markdown，放在你自己选的文件夹里，没有数据库，也没有自己的
格式。用任何编辑器打开这个文件夹，看到的和 vemry 看到的一模一样；哪天想换工具，把文件夹
拿走就行。

**AI 写入前先问你。** 每一条修改都停在一份 diff 上，由你允许、拒绝，或者改完再应用。
你标为隐私的内容，模型永远看不见，也察觉不到那里少了东西。

**离线照常工作。** 不用注册，没有遥测，除非你做了需要联网的事，否则什么都不会碰网络。
不配 API key，它仍然是一个完整的本地编辑器；接上跑在自己电脑上的模型，连 AI 也不出你的电脑。

## vemry 是什么

vemry 是一个 Markdown 文件夹的编辑器，加上一个按你的规则在这个文件夹里干活的 AI。
你看到的一切——编辑器、每个视图、AI 的工具、你自己的脚本——读的都是从你的文件建出来的
同一份块级索引。你的知识在任何地方都没有第二份副本。

它不是云服务，也不是一个挂着笔记文件夹的聊天窗。AI 是你知识库里的一个参与者：每次写入前
有一道权限门，隐私边界它看不过去。

读完一篇论文，你能用自己的话讲出来；哪里讲偏了，当场看到；快忘的时候，卡片把它带回来。
剪成 Markdown、对照翻译、整理归档、追出处、做卡片，这些繁琐的活不用你动手，每一次写入仍先
停在 diff 上等你点头。

## 你能用它做什么

### 专注写作，其余一敲就来

在行首敲 `/`，标题、待办、表格、代码、标注块都在同一个菜单里，边打字边筛选。⌘P 打开
命令面板，应用里八十多个命令、连同你的脚本加的命令，都能按名字搜到，输中文、英文都行。
从网页复制来的富文本，粘贴时会自动转成干净的 Markdown；不管用哪种方式写，存下来的始终是
标准 Markdown。

| 按键 | 作用 |
|---|---|
| `/` | 插入任意一种块 |
| `[[` | 链接一篇笔记，或其中的某一节、某一段 |
| `@` | 日期、截止日、优先级和引用 |
| ⌘P | 命令面板 |
| ⌘O | 按标题打开笔记 |
| ⌘⇧F | 全文搜索 |

### 想法冒出来，先记下再说

不管正在用哪个应用，按 ⌥⇧Space 就会弹出速记框。写一行，回车，它就进了收件箱，手头的事
不被打断。攒多了，让「整理速记」按主题把它们分进各自的笔记。

手机扫码配对之后，出门在外想到的也能随手记下，发进同一个收件箱：电脑开着，一秒内就到；
电脑关着，下次打开时取回。手机速记需要登录 vemry 账户（免费），记下的内容经由这个账户送到
你的电脑。

### 两种语言并排读

在内置浏览器里打开网页，点「译」，译文一段段贴在原文旁边，边读边出来。论文 PDF 按 ⌘⇧T：
左边是原页，右边是这一页的译文，每段都和原文对齐。点一段译文，原文里对应的那段就亮起来，
要核对只需一眼。

公式原样保留，图注和参考文献不送去翻译。笔记也能对照着读，可以并排、交错，或者只看译文；
译文还能另存成一篇笔记。可以译成中文、英文、日文、韩文、法文、德文、西班牙文等语言。

### 看到值得留的，一键剪进来

在内置浏览器里按 ⌘⇧S，整篇网页就成了 `clips/` 里的一篇笔记：正文、图片、原文链接、剪藏
时间都在。图片也存进你自己的文件夹，哪天原网页没了，笔记还在。只要其中一段？选中它，点
「选区→笔记」，它会带着出处落进你正在写的那篇。

论文更省事：贴一个 arXiv 链接，每一节、每个公式、每张图表都会变成可以单独引用的块。在
macOS 上，内置浏览器还能拦截广告和跟踪器。

### 一章一章读懂

读论文，选「研读论文」，再贴上链接，或者拖进一份 PDF。原文导入成一个个块，按章拆开；每一章
先连上你库里已经懂的内容，再讲新东西，用到的原文段落就嵌在旁边。

读完一章，用自己的话复述一遍：讲对了什么、漏了什么、哪个记号弄混了，会逐条指出来，每条都
链回原文。想动手试试这个想法？要一个实验，章节里就多出一个可运行的块，你点了运行它才跑。
平时读网页文章也一样：在阅读投影里读，有问题随时问，回答都注明出处。

### 快忘的时候再见一面

卡片只从你复述的缺口里来。复习视图按遗忘的节奏把它们送回来：想起来了点「记得」，下次隔得
更久；没想起来就点「重来」。卡片和复习记录都写在笔记里，还是纯 Markdown。

### 同一份笔记，按你的问题去看

今天该做什么，看日程；每件事推进到哪一步，看看板；这个月做了些什么，看时间线。哪些笔记互相
连着，看图谱；哪个论点有证据撑着、哪个还没有，看断言和证据；哪些卡片该复习了，看复习。它们
都不是另存的数据，全是对同一份索引的查询：在任何视图里勾掉一项任务，改的都是文件里的那一行；
在笔记里写一个 `vemry-query` 围栏，同样的查询就直接渲染在正文里。

### 提问，然后核对答案

每个答案都引用它读过的那个块，点引用就能打开。开着联网搜索时，每个来源都标明验证过没有；
想留下的答案可以作为一个块放进笔记。按 `@` 把一篇笔记、一个目录或当前选区交给 AI。

### 把杂活交出去，按你的规矩

十六个内置技能覆盖阅读之外的工作：整理文件夹、整理速记、重整一篇笔记、会议记录变行动项、
今日启动与今日收尾、从一周的笔记起草周报（由你收尾）。杂活交给 AI；读、复述和裁决留给你。
往 `.vemry/skills/` 里放一个 Markdown 文件就是你自己的技能。每次写入都是一份 diff，一整轮的
写入可以整体撤销，每场会话都是一份审计日志，在会话回放视图里逐条回放。

![写入门——这条编辑是 agent 提的；你不作答，它就不落盘](docs/assets/permission-diff.png)

### 用脚本自动化，不用装插件

往 `.vemry/scripts/` 丢一个 `.js` 文件，保存即生效。脚本可以注册命令面板条目、订阅
vault 事件、按 cron 定时运行，跑在一个无文件系统、无网络、无进程的沙箱里。

## 快速上手

1. **安装。** 到 [vemry.app/zh/download](https://vemry.app/zh/download) 下载适合你平台的
   安装包：macOS 是 Apple 芯片或 Intel 芯片的 `.dmg`，Windows 是 `.exe` 安装程序，Linux 是
   `.AppImage` 或 `.deb`。所有文件和校验值也在
   [Releases](https://github.com/pangyexing/vemry/releases) 上；也可以[从源码构建](#从源码构建)。
   - macOS 10.15 或更新。已签名并通过 Apple 公证，打开方式和其他应用一样。
   - Windows 10 或更新；缺少 WebView2 运行时的，安装程序会自动补上。安装程序暂未签名，
     SmartScreen 拦下时，点「更多信息」，再点「仍要运行」。
   - 带 WebKitGTK 4.1 的 Linux 发行版，比如 Ubuntu 22.04 或更新。用 AppImage 之前，先给它
     加上执行权限：`chmod +x vemry_*.AppImage`。
2. **打开示例知识库。** 先 clone 本仓库，再 ⌘P →「打开其他知识库…」→ 选
   `examples/demo-vault`。这是一位学习者 2026 年 9 月的一周，和官网讲的是同一个故事：一篇
   分章研读的论文，附两个能直接运行的实验，以及复述核对后留下的卡片；一个带任务的项目；一条
   带断言与证据的研究线；一页网上剪藏和一份用来对照翻译的讲义；一个收着电脑和手机速记的
   收件箱；几天日志、三段录下的 AI 会话，以及一个隐私目录。从「Start Here」这篇开始。
3. **选择 AI 怎么跑**（可选）。设置 → AI。自带 key 的话，在「你的提供方」里添加：任何
   OpenAI 兼容的端点、它的 key，以及它提供的模型 ID。智谱一开始就在；预设还能添加
   DeepSeek、OpenAI、Anthropic、xAI、Meta、月之暗面和 Z.ai，带上它们当前的模型（OpenAI、
   xAI、Meta 和 Anthropic 走各自当前的原生 API；这四家、DeepSeek 和智谱 GLM-5.3 能联网
   搜索）；「Ollama 本机」预设则接上你自己电脑上的模型。
   用「vemry 托管」的话，
   用邮箱登录，它的模型就出现在列表里，不用配 key：新账户第一次在桌面应用里登录，送 600 积分
   试用，14 天内有效，不用绑卡；之后托管算力随 [Pro](#免费与-pro) 提供。当前模型在设置里选，
   也可以在对话的模型菜单里切换。两种方式下，请求都原样到达模型厂商。
4. **研读一篇论文。** 打开 AI 面板，选「研读论文」，贴一个 arXiv 链接或拖进一份 PDF。
   原文笔记、章节、卡片都以 diff 的形式到来，由你确认。

这就是整个闭环。它做出来的每一样东西，都是你文件夹里的一个 Markdown 文件。

Windows 和 Linux 上，把 ⌘ 读作 Ctrl，把 ⌥ 读作 Alt。

### 先试试这几句

在任意应用里按 ⌥⇧Space，记下此刻想到的第一件事。然后打开 AI 面板（在任何地方按 ⌘J），
输入其中一句：

```
研读这篇：https://arxiv.org/abs/1706.03762
这是我对第 3 章的复述：…… 哪里和原文偏了？
给我一个 3.2 节的实验，能在这里直接跑。
用今天到期的卡片考考我。
这个库这周改了什么？
整理一下 research/ 目录。
```

示例知识库里的 `private/` 已经是隐私区：让 AI 列出你的笔记，它看不见这个目录，也不会知道少了什么。

## 什么留在你的机器上

**隐私即不存在。** 把一个目录、一篇笔记或单独一个 `> [!private]` 块标为隐私，agent 就永远
不读、不写、也不会在 prompt 里见到它。这在 Rust 层的每个读写卡点上强制执行，而且一个隐私
文件返回的错误与一个从来不存在的文件逐字节相同。要用云端模型，就先划好隐私区。

**每次写入都停在一份 diff 上。** 允许、拒绝，或者改完再应用。这道门就在掌握文件访问能力的
那一层 Rust 里，界面上没有任何东西能绕过它。

**五个网络出口，每一个都由你触发；登录后才有第六个。** 不登录时，vemry 只在这几种情况下
碰网络：你配的 AI 端点、你打开的网页、阅读投影里的图片或你在笔记里点开的远程图片、你订阅的
去广告规则、检查更新；用你自己的 key 时，请求直接从你的电脑发往你选的厂商。登录之后多出
vemry 账户这一个出口：托管算力的中继原样转发每一次请求，不保存提示词，也不保存回答；还有
手机速记的收件箱。这些出口列在 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) 里，服务器存什么写在
[隐私政策](https://vemry.app/zh/privacy)里，其余一切断网照常。

**任意代码永不自动执行。** 打开一篇笔记不等于运行它。每条执行路径都始于你的某个动作，
而 agent 根本没有能执行代码的工具。

## Markdown 方言

语义用别的工具本来就认识的普通 Markdown 表达：

```markdown
- [ ] 一个任务 📅 2026-08-20          ← 截止日期
- [/] 进行中
- [x] 已完成

> [!claim] 睡眠巩固记忆 ^c1                      ← 断言，带块 ID

> [!evidence] Walker 2017 的剥夺实验
> supports:[[睡眠与记忆#^c1]]                    ← 证据，指向那条断言

![[睡眠与记忆#^c1]]                               ← 只读嵌入那个块
- 再读 [author:: 勒古恩] [status:: reading]      ← 行内字段：可查询、可分组
```

上面每一条在别处都渲染成一个列表项或一段引用。完整方言与逐条降级形态见
[docs/SYNTAX.zh-CN.md](docs/SYNTAX.zh-CN.md)。

## 从源码构建

```bash
git clone https://github.com/pangyexing/vemry.git
cd vemry
pnpm install          # 只用 pnpm：锁文件和 pnpm-workspace.yaml 里的供应链设置都是 pnpm 的
pnpm tauri dev        # 需要先 source ~/.cargo/env
```

需要 Rust（stable）与 Node 22+。打包版的更新经 minisign 签名，用编译进应用的公钥校验；
下载与安装始终需要你确认，启动时自动检查默认关闭。
